Technical Events (Brief Description)
1. Coding Contest
- Individual event
- Tests basic programming logic
- Focus on speed and accuracy
- Languages: C, C++, Java, Python

2. Web Designing
- Individual
- Design a webpage for a given problem statement
- Technologies: HTML, CSS (basic JS optional)
- No templates or frameworks
- Emphasis on layout and design accuracy
- Time-bound event

3. Tech Quiz
- Team of 2
- Multiple rounds (MCQ, rapid fire, buzzer)
- Covers core CS and current technologies
- Tests technical knowledge and presence of mind
- Elimination after each round

4. Debugging
- Individual event
- Programs with logical/syntax errors
- Languages: C / C++ / Java / Python
- Identify and fix bugs
- Focus on code understanding
- Time-limited

5. Reverse Engineering (Guess the Output)
- Individual participation
- Predict output of given code snippets
- No compiler allowed
- Tests logical thinking and code analysis
- Languages: C / Java / Python

6. Paper/Poster Presentation:
- Team of 2–3
- Present on emerging technologies (AI, IoT, Blockchain, Cyber Security, etc.)
- PPT + oral presentation
- Judged on content, clarity, innovation, and presentation skills
